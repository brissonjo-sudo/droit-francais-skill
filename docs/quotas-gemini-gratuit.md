# Préparation Gemini gratuite — 10/10/2026

La clé gratuite remplace l’hypothèse OAuth initiale. La campagne garde son
gel gratuit fermé : aucun quota actif ni moteur réel n’est qualifié ici.
Le prototype REST, les profils et compteurs sont préparés dans une PR séparée.

RPM, TPM et RPD doivent être relevés pour le modèle et le projet exacts,
avec une preuve récente ; les clés d’un même projet partagent ses limites.
Consulter la [documentation Google](https://ai.google.dev/gemini-api/docs/rate-limits).
Aucun calendrier Gemini n’est déduit de chiffres communautaires.

Voir [le protocole](campagne-18-modes.md). Claude/Codex utilisent leurs
clients natifs ; toute comparaison inter-familles confond modèle et moteur.
