# Suivi volontaire du pilote

Aucune télémétrie automatique n'est ajoutée. Le retour est fourni volontairement
par le testeur, sans question juridique, réponse, document, compte ou secret.

J0 correspond à la première tentative d'installation de chaque testeur,
réussie ou bloquée. J+7 et J+30 se comptent à partir de cette date, pas de
la fusion d'une PR. Le testeur peut arrêter le suivi à tout moment ; aucun
rappel automatique ni message à un tiers n'est prévu.

À J+7, recueillir : canal/client/version, installation réussie ou étape de
blocage, méthode visible, premier appel source réel réussi, temps d'installation
par tranche et besoin d'aide. Distinguer installation et accès aux outils.

À J+30, recueillir : réutilisation volontaire (oui/non), usage par tranche,
utilité perçue (référence, raisonnement, audit documentaire), limite rencontrée
et intention de poursuivre. Ne pas déduire l'adoption des étoiles GitHub.

Le formulaire tient en une issue assainie ou un retour privé consenti.
Une issue publique rend visibles le pseudonyme et le contenu du retour ;
proposer la voie privée si le testeur préfère. Le suivi est une proposition
de pilote, pas la preuve qu'une cohorte a commencé ni qu'un retour existe.
Le bilan publiera des effectifs et une période ; jamais un taux sans dénominateur.
La description GitHub proposée est :
« Méthodologie de recherche en droit français, 18 modes d'erreur, sources
primaires, contrôle de vigueur et outils MCP Légifrance/Judilibre. »
Topics proposés : french-law, legal-research, agent-skills, mcp, legifrance.
Cette description a été appliquée et relue sur GitHub le 10/10/2026, en
cohérence avec les 18 modes du noyau. Les topics restent des propositions ;
les topics existants n'ont pas été modifiés.
